# Media Tracker Frontend

Frontend for my Media Tracker application.

## Features

- User registration and login
- JWT authentication
- View personal media collection
- Add media entries
- Edit media entries
- Delete media entries
- Search for and filter by media entry features
- Pagination
- Responsive user interface

## Tech Stack

- React
- React Router
- CSS

## Backend

## Running Locally

1. Clone repository
2. Install dependencies

npm install

3. Start development server

npm start

## Deployment

Frontend deployed on Vercel.
